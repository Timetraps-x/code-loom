# Multi-Stack Repository Adoption

## Repository evidence

A monorepo contains a Spring/MyBatis API, a React application, and shared contract definitions. Root rules define shared ownership and generated-contract boundaries. Each application has different test and build commands and distinct local code-shape examples.

## Expected judgment

- Produce one shared constitution for cross-stack ownership and contract boundaries.
- Add only short stack-local rules supported by representative local code.
- Recommend all actual languages, frameworks, stable module families, and exact commands separately in the project profile.
- Do not generate a full constitution per stack or flatten stack differences into generic rules.
