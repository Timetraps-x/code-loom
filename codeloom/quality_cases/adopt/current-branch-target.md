# Current Branch Design Is Not Durable by Default

## Repository evidence

A branch-local plan proposes moving orchestration into a new workflow module. The directory is untracked, no released path uses it, and project documentation still assigns orchestration to existing application services.

## Expected judgment

- Classify the proposed module as target-only.
- Do not place its names or boundaries in the constitution without stable repository evidence or explicit Owner promotion.
- Preserve the currently supported ownership rule if it remains evidence-backed.
- Report a material promotion conflict only if adoption guidance explicitly asks to make the target design the long-term standard.
